    这个图现在是完整的吗？

    不是。这一轮用 9 条真实轨迹把 OmniNotes 的 10 个功能长成了 56 条契约边、399 条可组合路径， 覆盖了“建笔记 → 打开 / 搜索 / 排序 → 分享 / 归档 / 固定 / 待办 / 删除”这条主线。 完整不是一次采完的，而是靠三件事持续推进：

    • 再探索一条轨迹：新功能变成新卡片，新顺序变成 sequence 边——就是上面这个动画。
    • 失败驱动修补：执行失败时按失败类型回写卡片的前后条件或边的类型，图越跑越准。
    • 能力补全：目标在图上不可达时，让模型提出缺失能力的探针轨迹，采回来补进图。

    为什么这个图能拿来卖

    单张卡片只能做一件事，测试能力是组合出来的。 每加一条 enables 边，可规划的测试数量就不是 +1，而是把已有的路径和新的前置条件接起来。 这就是上面那个“可规划的多卡路径”数字从 0 涨到 399 的原因—— 这些路径里没有一条是被完整录过的，它们是从图里推出来的。

    同一份图可以直接给规划器用： planner 在 enables / sequence 上搜索，dataflow 只负责给参数， 所以“数据上能接、UI 上进不去”的假路径不会被选中。
