Release · 2026-11-18

v0.3.0 — 探针与能力补全走 agent

能力补全不再依赖预先写好的探针脚本：一个能力假设被渲染成任务描述， 交给同一个 GUI agent 去尝试，它看到什么就做什么。

v0.3.0 latest 在 GitHub 上查看 → 源码快照

本版本包含

  • 探针经 AgentProbe 交给 agent，与 benchmark 执行器是同一个客户端。
  • 修复：探针计划漏传包名，agent 会在错误的 app 上行动；已加回归测试。
  • 能力假设只写意图与前后置条件，不再让模型预先猜控件。
  • 真机验证：探针任务六步执行，每步带动作前 UI，trace 记录最终状态。
  • 419 个测试通过。

Release · 2026-11-18

v0.2.0 — 卡片是契约，计划是描述，agent 执行

架构切换：卡片不再记录 UI 动作，只声明意图、输入、前后置条件与产出； 规划器的输出变成一段任务描述，由 GUI agent 执行。图从此描述 App 的功能， 而不是回放某一次录制的动作。

v0.2.0 在 GitHub 上查看 → 源码快照

本版本包含

  • 卡片去掉 Steps；解析器显式拒绝旧格式，93 张卡已迁移且幂等。
  • 新增 TaskDescriber：确定性渲染整体 goal 与有序 subgoals，不点名任何动作。
  • 新增 GuiAgent 协议与 MobileAgentBackend；Executor 只交描述、只做 goal 判定。
  • agent 不再自己启动 app，不再清掉 benchmark 准备好的状态。
  • 删除 StepCompiler / PlanStep / DeviceProbe / execute_plan / SpecFCGAgent / granularity。
  • 真机验证：MobileAgentBackend 逐步记录动作前后 UI；规划→描述→执行→判定返回成功。
  • 417 个测试通过。

Release · 2026-11-18

v0.1.0 — Stage 1 MVP 与实验环境

第一个可运行版本：从真实轨迹归纳 function card、建 Function Contract Graph、按目标规划并在真机上执行，失败后回写卡片。实验侧补齐了四个 App 的 MobileWorld 基准、随机遍历对照与分数记录；本机实验环境改为 Android 模拟器 + 本地 vLLM 的 Qwen3.8-27B。

v0.1.0 在 GitHub 上查看 → 源码快照

本版本包含

  • 卡片、图、规划、执行、修补的完整链路在真机上验证，三个组合目标 3/3 通过。
  • 448 个离线测试通过，CI 覆盖 Python 3.10 与 3.12。
  • 四个 App 各建一张图，分数记录 7 次迭代，最新综合 71.7。
  • 实验环境迁到 Android 模拟器；LLM 从 Magpie 网关切到本地 Qwen3.8-27B（256k 上下文、OpenAI 工具调用）。
  • 已知限制写进报告：20 个任务不足以做显著性结论，标定维度是 bias-only。
