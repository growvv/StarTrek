Stage 1 MVP

从轨迹归纳卡片、建图、按目标规划、真机执行、失败回写，全部在真机上跑通。 已完成 17/17。

1配置与 LLM 客户端已完成

2共享模型与卡片解析已完成

FunctionCard / Edge / Graph 与 Markdown 卡片格式。

3卡片与图的存储已完成

卡片落盘、边落盘、图版本与补丁日志。

4图搜索已完成

BFS / DFS / A*，供规划器取可达路径。

5轨迹采集已完成

脚本化采集、录制与 ProphetAgent 输出适配。

6卡片归纳已完成

LLM 切分 episode 并写卡片，输入参数做 grounding。

7边构建已完成

enables / dataflow 由 LLM 判断，sequence 来自轨迹。

8设备抽象与状态摘要已完成

uiautomator2 桥接与 UI 压缩摘要。

9执行器已完成

逐步执行动作并按 postcondition 校验。

10卡片检索与参数绑定已完成

goal 里的值映射到卡片 inputs，未绑定的才问 LLM。

11动作编译与规划器已完成

卡片步骤编译成具体 UI 动作，规划器串起路径。

12图更新器已完成

失败归因后改卡片、改边或加卡，保留改前版本。

13能力补全已完成

预测缺失能力并用探针验证。

14流水线与 CLI已完成

mine / build-graph / plan / run 四个子命令。

15ProphetAgent 适配已完成

解析外部 agent 的输出，作为轨迹来源之一。

16基准测试框架已完成

任务套件、agent、程序化 oracle 与分数卡。

17Stage 1 数据与报告已完成

清单、报告与公开证据副本。
